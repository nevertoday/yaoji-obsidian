# 对抗测试 · 2026-10-28

对象：0.1.4 以后新加的「做几次」（`×3`）、「以前还剩 N 件」菜单，以及侧边栏改日记的整条路（点方框、+1、星标、发到 GitHub、删除 / 撤销、带到今天 / 撤销）。
做法：随机生成日记（多行任务、Tab / 2 / 4 空格缩进混着、代码块、缩进标题、Windows 换行、同名任务、只有次数的任务……），每种操作做一次再做反过来的那一次，文件要一字不差回到原样；另外看写回后每段说明是不是还在原来那件事下面。
本机接口按 10/25 那轮的打法重跑一遍（`tests/bridge.test.mjs` 里真开接口的那些），都挡住了，这次没有新改动。

## 打穿了、已修（扩展 core/markdown-parser.js、core/todo-count.js，两边共用）

| # | 严重 | 问题 | 修法 |
|---|---|---|---|
| 1 | 高 | Windows 换行（\r\n）的日记：事项这一节最后一件有第二行、后面紧跟下一个标题时，侧边栏里点任何一件的方框，那第二行就被删掉 | 读续行时行尾的 \r 不算字 |
| 2 | 中 | 点小数 +1（改了那一行的字）：那件事下面没缩进的说明、图片跑到上一件下面；它是第一件就跑到这一节最上面。发到 GitHub 接上问题地址也一样 | 新旧两份按顺序对齐，两件对上的之间新旧都只空出一件的就是同一件 |
| 3 | 中 | 好几件同名的、其中一件改了字：别的同名任务下面的说明错位到隔壁那件 | 先按顺序对齐（最长公共子序列，前后没变的直接配上），再按名字找拖走的 |
| 4 | 低 | 任务下面一行只有空格：任务写回时挪浅一级，这行成了它的第二行，星标认不出来 | 续行末尾只有空格的行不算这件事的字 |
| 5 | 低 | 次数到 9999 再 +1 写成「×10000」，读不回来，下次成了「×10000 ×1」 | 最多 9999 |
| 6 | 低 | 只有次数的那件（「×5」）+1 写成「 ×6」，前面多一个空格 | 不加空格 |
| 7 | 低 | 侧边栏点 +1 时这一行刚在别处改过、没写进去，照样提示「第 N 次」还给撤销 | 没写进去就不提示，清单重画 |

## 没修、记着

- 删除后这篇又改过再撤销：那件放回原处，但它下面没缩进的说明留在删除后挪去的位置（没改过就整篇换回，一字不差）。
- 同一节里缩进很乱（一级任务写成 8 个空格，下面一行说明 4 个空格）：写回时任务挪到顶格，那行说明成了它的第二行。字都在。
- Windows 换行 + Tab 缩进的续行：第一次写回时还是 Tab，再写一次换成 4 个空格。字都在。
